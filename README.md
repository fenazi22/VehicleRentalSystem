# Vehicle Rental System

A simple Java project for practicing object-oriented programming through a vehicle rental scenario.

## Focus Area

- Java fundamentals
- Object-Oriented Programming
- Classes and objects
- Encapsulation
- Basic application logic
- Console application structure

## Project Idea

This project models a simple vehicle rental process and helps practice organizing code around real-world entities.

## Learning Goals

- Practice creating Java classes.
- Apply OOP concepts.
- Organize simple business logic.
- Improve code readability.
- Build a small Java application from a clear scenario.
